# 中国象棋 · 智算单机版 v2.12（安卓版 / 桌面版）

同一份程序，两个版本。规则、AI、残局库、按钮文案完全一致，只在「怎么操作、东西放哪」上按平台各让一步。

## 两个版本各有什么好

| | 安卓版 | 桌面版（Windows exe） |
| --- | --- | --- |
| 操作 | 手指点选，拖动走子 | 鼠标点选 / 拖动，右键摆棋删子 |
| 布局 | 竖屏全屏，底栏两排 4+4（悔棋·提示·复盘·存局 / 认输·提和·棋谱·重开），左上角房子图标回主页，按钮高约 92 逻辑像素 | 一排九个按钮，窗口可缩放，信息更密 |
| 启动 | 直接出主页，残局库等重活丢后台，点菜单时基本已备好 | 窗口即开 |
| 导入曲子 | 设置里直接「导入曲子 / 删曲」 | 系统文件对话框，可一次选多个文件 |
| 键盘 | 只有返回键（浮层先关 → 对局回主页 → 主页退出） | Esc 关浮层、回车确认 |
| 数据位置 | 应用私有目录，不占相册、不要存储权限；卸载即清 | exe 旁边的 `象棋设置.json`、`残局库.json`、`曲/`、`棋谱/`，拷走就能搬机器 |
| 适合 | 随手一局、通勤、躺床上摆残局 | 认真摆棋、整理棋谱、批量传曲子 |

## 目录

| 文件 | 作用 |
| --- | --- |
| `main.py` | 安卓启动入口（记启动日志、屏幕探针、崩溃时显示红屏堆栈） |
| `xiangqi.py` | 主程序 v2.12（与桌面版同一份，含内置 214 局残局库） |
| `buildozer.spec` | 打包配置：包名 `org.songyq.xiangqi`、竖屏全屏、arm64、`version = 2.12` |
| `icon.png` | 512×512 图标，同时当启动闪屏 |
| `.github/workflows/build-apk.yml` | GitHub Actions 云构建脚本 |

## 云构建

1. 仓库推到 `main` 分支。
2. **Actions → 打包安卓 APK → Run workflow**。
3. 开头有一道「核对仓库里的程序版本」：读 `xiangqi.py` 的 `VERSION` 与 `buildozer.spec` 的 `version`，不一致、或低于 2.9，**几秒内直接失败**，不会白等一小时。
4. 成功后在本页 **Artifacts** 下载 `中国象棋-apk-r<运行号>.zip`，里面是 `xiangqi-2.12-arm64-v8a-debug.apk`。
5. 传到手机安装；已有旧版可直接覆盖（签名一致）。

## 怎么确认装的是新版

1. Artifacts 名字带 `-r` 编号；不带编号的是老包。
2. APK 文件名带 `-2.12-`。
3. 装好打开，主页右下角落款是 `v2.12`；应直接看到主页（无开机动画），上下无黑边。
   进残局库看标题：应写「残局库 219 局」，不再是 8 局。
4. 还显示旧版本号 → 查看本次构建页面顶部的「本次构建版本」表格，确认仓库里的文件确实换了。
   网页上传同名文件后**必须点 Commit changes**，否则文件没变，编出来还是旧代码。

## 本机构建（Linux / macOS / WSL，Windows 原生不行）

```bash
pip install buildozer cython==0.29.36 virtualenv
sudo apt install -y git zip unzip openjdk-17-jdk autoconf libtool \
    pkg-config zlib1g-dev libncurses-dev cmake libffi-dev libssl-dev
buildozer -v android debug
```

## 已知限制

- debug 包用调试密钥签名；装手机要允许「未知来源」，上架商店需另配 release 签名。
- 安卓上 pygame 不弹输入法，需要键盘的地方（摆棋自定义输入等）用不了；走子、残局、设置、音乐、导入曲子都正常。
- `曲/` 里的 mp3 能否播放取决于打包时 SDL_mixer 是否编译了 mp3 支持；不支持时自动回落到内置合成古曲。
