# 中国象棋 · 智算单机版

一份代码，两个版本：Windows 桌面版（EXE）与安卓手机版（APK）。规则、AI、残局库、棋谱全部共用同一个 `xiangqi.py`，只在界面尺寸与输入方式上分叉。

当前版本 **v2.16**（安卓 `version = 2.16` / `numeric 21600`）。

## 两版各自的长处

| | 桌面版 | 安卓版 |
| --- | --- | --- |
| 操作 | 鼠标点选，键盘快捷键 | 单指触屏，按键按 dp 放大 |
| 画面 | 窗口可拖边角缩放 / 可最大化，等比不拉伸 | 竖屏全屏，16:9～22:9 自适应重排 |
| 存档 | 程序目录下的 `残局库.json` / `象棋设置.json` | 应用私有目录，卸载即清，无需存储权限 |
| 分发 | `dist\中国象棋-智算单机版-v2.16.exe`，双击即玩 | GitHub Actions 云构建 APK，手机侧装 |
| 输入法 | 支持残局改名、粘贴棋谱 | pygame 不弹软键盘，这两项手机版不可用 |

## 功能

- 人机对弈：三档难度，开局库起手，中局按子力与位置估值搜索
- 残局库：内置 214 局（压缩进主程序兜底），可导入 / 导出 / 改名 / 删除，按开局·中局·残局分阶段筛选
- 议和与认输：电脑判断局面和棋或必败时主动提出，拒绝后可以再提，最多三次；再拒绝则认真下
- 长将判负：同一局面重复三次且构成连续将军的一方判负
- 音效与古曲背景音乐，可分别开关；支持导入本地曲目（最多 4 首）
- 棋谱：对局记录、复盘、备份残局库（保留 3 份，可一键恢复）

## 桌面版

```bash
py 中国象棋-智算单机版-v2.16.py     # 直接运行
py 打包_象棋.py                     # 打成 dist\中国象棋-智算单机版-v2.16.exe
```

## 安卓版（云构建，本机无需装 Android SDK）

1. 把本仓库根目录的 `xiangqi.py`、`buildozer.spec`、`main.py`、`presplash.png`、`icon.png` 放在同一层。
2. 仓库 **Actions** → 左侧「打包安卓 APK」→ **Run workflow**。
3. 第一次约 40–70 分钟（要装 SDK / NDK 并编译 CPython），之后有缓存会快很多。
4. 跑完在本次运行页底部 **Artifacts** 下载 `中国象棋-apk-r<轮次>`，解压得到
   `中国象棋-2.16-arm64-v8a-debug.apk`。
5. 传手机安装，首次需允许「安装未知来源应用」。覆盖安装不会清数据。

工作流第一步会打印 `xiangqi.py` 的 `VERSION`、`buildozer.spec` 的 `version` 与 `numeric_version`，三者应分别是 `2.16 / 2.16 / 21600`；出包前还会核对 APK 文件名里带不带 `-2.16-`，对不上直接报错，避免再拿到旧包。

## v2.16 手机屏幕适配

- **矮屏不再压棋盘**：以前手机布局按「理想尺寸」一摆到底，16:9（逻辑 572×1017）和 4:3 平板放不下，红方计时面板就压在棋盘最后一排上——1080×1920 压 15 像素，最底排棋子被盖住。现在把所有弹性尺寸（顶栏、计时面板、说明行、两排按钮）按同一系数整体收紧，二分出放得下的最大值，矮屏收一点、谁也不压谁。
- **长屏铺得更满**：画布高度上限从 1400 放到 1600，20:9 / 21:9 / 22:9 的手机不再在上下留木色条，画面铺满整屏。
- **矮屏兜底**：画布高度下限 936，是「控件压到最小也不重叠」的底线；4:3 平板、折叠屏这类偏方的屏幕按高度铺满，左右留木色边（棋盘宽度固定 572，硬拉宽会把格子拉变形）。
- **启动再量一次屏**：少数机型刚进全屏时报的还是旧可用高度（导航栏还没真正让位），启动阶段会再量一次，比例差两行以上就按新尺寸重排一遍，不再多出一条边。
- **桌面不受影响**：窗口拉伸那套逻辑只在桌面走，安卓仍是竖屏全屏、不做可拉伸窗口，也不吃 `VIDEORESIZE`。

## v2.15 桌面版调整

- **底部按键不再被切**：桌面底栏原来排在 y=832、高 26，而画布只有 838 高，按钮下沿到 858，有 20 像素落在屏幕外，看起来就是「下方按键被遮挡」。现在画布加高到 884，底栏贴底排（842–876，高 34），红方面板、说明两行、底栏各占各的位置，互不重叠。
- **按钮变大、字变清楚**：桌面底栏高度 26 → 34，字号 13 → 15；红方面板与底栏之间留 14 像素，说明文字不会再贴住按钮。
- **窗口可以拉伸**：桌面窗口改为可调整（拖边框 / 右上角最大化），画面保持等比缩放、居中不做重排，所以拉大就是整体放大，不会出现字压字；缩到 420×646 以下会被夹回去，免得点不准。
- **留边不再刺眼**：窗口比例不是竖屏时，左右或上下的留边用棋盘木色填充，不再是纯黑；窗口缩放后鼠标坐标每次按真实尺寸换算，点按钮不会偏。

## v2.14 手机版调整

- **摆棋存盘可以退回来了**：命名浮层底部新增「保存」「返回」两个大按钮（150×56），点「返回」就是取消，不再只能靠 Esc；取消时会明确提示「没有存盘」。
- **摆棋界面不再压字**：底板、按钮、提示文字改成按棋盘下沿现算，棋盘下移时跟着下移；手机版棋子格 31×36、按钮高 54（长屏 64），字号从 15 提到 17。
- **残局库按手机重做**：一屏 10 行（原来是 20 行小字），行高 58，局名 21 号字，第二行放局号 / 难度 / 状态 / 存盘日；行尾 ★ 与 × 放大到 46×46 / 44 宽。
- **滚动条加粗**：手机上 22 像素宽，拇指一按就能拖，另外整个列表都能上下划。
- **划动翻页、点一下载入**：按下先不动手，位移超过 8 像素才算拖动（按行换算），原地抬手才载入这一局，手指一划不会再误开残局。
- **复盘按键字更大**：底栏「复盘」用比其余按键大一档的字，复盘模式里「上一手 / 下一手 / 自动 / 退出复盘」也按手机高度放大。
- **启动不再误点**：进主循环前先把主页画出来，随后 0.9 秒内的触摸一律丢掉，启动时连敲屏幕不会再误入对战或残局。

## v2.13 修的三件事

- **启动不再闪「象」字图标**：启动闪屏从 `icon.png` 换成与主页同色的纯米色 `presplash.png`，SDL 层铺底色，主页首帧直接接上。桌面图标仍是 `icon.png`。
- **启动变快、连敲不再闪退**：进入主循环前清掉积压的触摸事件；后台读残局库未完成时只放行退出与窗口事件，不再让主线程等后台线程；古曲音符波形加缓存，去掉启动时白白合成的三段音效波形。
- **退出不再红屏报错**：缩放贴图不再用启动时算好的固定矩形取子区域（安卓退出 / 切后台 / 旋屏会先缩掉显示 Surface，矩形一越界就抛 `ValueError: subsurface rectangle outside surface area`），改成每帧按真实尺寸重算并做边界检查，越界时回退离屏缩放 + blit；收到退出后不再画最后一帧；错误提示页也从等 120 秒改成提示点屏返回。

## 数据文件

- `残局库.json`：残局条目；缺失时用内置 214 局自动补一份
- `残局库_已删.json`：删过的条目名单，防止内置库把它「补回来」
- `象棋设置.json`：难度、音效、音乐、步限等

## 已知限制

- debug APK 用调试密钥签名，安装时需允许未知来源；上架商店要另配 release 签名。
- 安卓上 pygame 不弹输入法，残局改名 / 粘贴棋谱用不了；走子、残局、设置、音乐都正常。
- 安卓 12 及以上系统自带「启动画面」会显示应用图标（系统行为，不受 `presplash` 控制）。
- `曲/` 里的 mp3 依赖打包时 SDL_mixer 是否带 mp3 支持，不支持会自动回落到内置合成古曲。
